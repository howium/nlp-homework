# NLP Coursework

自然语言处理课程作业仓库。每次作业放在独立文件夹（`hw1/`、`hw2/`、…）中。

## 环境

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> torch 需按显卡选择对应 CUDA 版本，例如：
> `pip install torch --index-url https://download.pytorch.org/whl/cu126`
